# Changelog

All notable changes to the Novel Team project are documented here.

## [3.0.0] — 2026-05-09

### Major Restructure
- Complete rewrite of SKILL.md — moved from a single persona-based skill to a full novel development system with 10-stage workflow, story bible template, world outline template, rolling summary system, and structured knowledge repository.
- Separated book-specific content from reusable skill templates. Project directories now live outside the skill.
- Added the **Review Gate** as the highest-priority rule: CREATE → REVIEW → FIX → PRESENT TO AUTHOR.
- Added the **Perception Phase**: each reviewer must read critically, quote specific lines, raise minimum 5 hard questions.
- Added the **Act Break Full-Stack Review** (Stage 5c) — comprehensive quality gate at act boundaries.
- Added **Cross-Chapter Continuity Pass** (Stage 5b) — run every 5-10 chapters.
- Added **Stage Discipline** rules: never advance without author confirmation, Stage 1 is mandatory even for sequels.

### Team & Personas
- Reworked all 8 team member persona files with distinct voices, clear expertise boundaries, and communication styles.
- Added full ROSTER.md with role boundaries table.
- Expanded editorial team: Alex (developmental), Jordan (line), Taylor (copyedit), Morgan (proofread/beta).
- Expanded specialists: Riley (research), Casey (continuity), Quinn (fact-check).
- Added Sam as writing coach (support team).

### Documentation
- Added QUICKSTART.md with usage patterns and team member quick reference.
- Added WORKFLOW.md with detailed 10-stage walkthrough and checklists.
- Added EXAMPLES.md with 5 real team-in-action scenarios.
- Added `references/role-research-methodology.md`.
- Added `templates/` for chapter brief, character profile, rolling summary, and setting profile.
- Added CHANGELOG.md, CONTRIBUTING.md, and MIT LICENSE.

### Templates
- Story bible template with sections for overview, timeline, character registry, plot threads, setting registry, technical references, tone & voice guide, and revision history.
- World outline template for military/thriller fiction worldbuilding.
- Chapter brief template combining scene breakdown with character and world details.
- Character profile template with appearance, personality, backstory, arc, and role boundaries.
- Rolling summary template for chapter-by-chapter state tracking.
