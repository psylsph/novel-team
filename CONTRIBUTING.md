# Contributing to Novel Team

Thanks for considering contributing to the Novel Team project! This is an open system for AI-assisted novel development, and contributions that make it better for everyone are welcome.

## What Kinds of Contributions Are Useful

### New Persona Files
A new team member role with a distinct voice and expertise. Before creating:
- Check it doesn't overlap with existing roles (Alex/Jordan/Taylor/Morgan/Riley/Casey/Quinn/Sam)
- Define clear boundaries — what they DO and DON'T address
- Write a persona file with distinct communication style

### Workflow Refinements
- Additional stages or substages for the development pipeline
- Improved checklist items for existing stages
- Better decision gates or review criteria
- Templates for new document types

### Template Improvements
- New reusable templates (e.g., synopsis template, query letter template, chapter outline)
- Improvements to existing templates (more useful sections, clearer instructions)
- Examples showing templates in use with real content

### Documentation
- Better examples for EXAMPLES.md
- Clarifications or corrections in SKILL.md, WORKFLOW.md, or QUICKSTART.md
- Use-case guides (e.g., "Using Novel Team for Non-Fiction", "Adapting for Screenplays")

### Bug Fixes
Yes, even a documentation repo has bugs — typos, broken links, contradictory rules, unclear instructions.

## How to Contribute

1. **Open an issue first** — describe what you want to add or change. This avoids wasted effort if it's already being worked on or doesn't fit the project's direction.
2. **Fork the repo** and create a branch for your change.
3. **Make your changes** — follow the existing style and structure.
4. **Test** — if adding a workflow rule, walk through it mentally. If adding a template, fill it out for a sample project to verify it works.
5. **Submit a pull request** with a clear description of what changed and why.

## Style Guidelines

- **Persona files** — write in first person with a distinct voice. Include: role title, expertise areas, boundaries, communication style, sample responses.
- **Workflow stages** — use the existing template: Goal, Participants, Checklist (bullet points with `- [ ]`), Decision Gate, Deliverable.
- **Templates** — markdown with clear section headers, placeholder text in `[brackets]`, and brief instructions.
- **Documentation** — write for both AI agents and humans. Keep sentences clear. Use examples.

## Code of Conduct

Be respectful. The goal is to help people write better novels — everyone's at a different point in their writing journey.

## Questions?

Open a discussion or issue. The maintainer (psylsph) typically responds within a few days.
