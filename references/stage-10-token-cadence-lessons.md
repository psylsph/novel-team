# Stage 10 Token + Cadence Lessons

Use during sustained `continue` drafting runs when the plan is already approved and scene breakdown exists.

## Token/context discipline

- Read only the current chapter scene slice, previous chapter tail/carry-forward, and compact progress state.
- Do not reload full planning packages, full skill docs, or broad reference files unless the chapter introduces a new specialty requirement.
- Keep final reports compact: files, verification, recent running table, What happens, Carry-forward, Next required chapter.
- Prefer targeted meta-leak/safety searches over broad manuscript scans each chapter; reserve broad scans for act breaks/final handoff.

## Scene cadence

- Default to 3 scenes per chapter when Stage 8 has a reviewed scene breakdown and no chapter-specific exception.
- Prior Unit 985 precedent (Bikini Black) used a mostly 3-scene cadence, with limited action-heavy exceptions; use 3 scenes as the default drafting discipline for follow-on books.
- If a chapter needs 2/4+ scenes during drafting, record why in the review and carry-forward rather than silently changing cadence.

## Review/scanning pitfall

- Whole-word meta-leak scans can flag legitimate in-world names such as Alice. Inspect context before editing.
- If a legitimate name is also a persona/meta name and a natural in-world alternative exists in formal narration (e.g. surname/title), a small wording adjustment is acceptable; do not blindly delete or distort character references.
