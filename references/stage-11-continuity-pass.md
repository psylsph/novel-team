# Stage 11 — Cross-Chapter Continuity / Mission Logic Pass

Every 5-10 chapters (and again after first draft is structurally complete), run a full continuity audit.

Read `references/continuity-audit-methodology.md` before starting this stage.

## What to Check

- timeline: do all chapter timestamps align?
- injuries/fatigue: are character physical states consistent?
- travel: does geography and elapsed travel time make sense?
- who knows what: does knowledge carry forward correctly?
- mission objective drift: has the team's goal changed without justification?
- enemy reaction: does Sokolov adapt to the team's moves?
- political consequences: do allied/political developments carry forward?
- open clues: are seeded plot threads picked up later?

## Continuity Audit Scope

Run these checks from the continuity-audit-methodology.md reference:

1. **Timeline anchor** — Extract all timestamps, build a master timeline. Fix contradictions.
2. **Numeric consistency** — Extract every stated number. Verify arithmetic cross-chapter.
3. **Character fate tracking** — Every named character's status must be resolved or deliberately left open.
4. **Plot consistency** — No duplicate events, no parallel timelines that should intersect but don't.
5. **Setting consistency** — Locations don't move without explanation.
6. **Loose threads** — Every seeded thread must be closed or explicitly carried to the next book.
