# Fast Track Workflow: Writing from an Existing Outline

**When to use:** You have a complete outline and want to start writing immediately.

**Skip:** Stages 0-4 (Seed → Concept → Characters → Structure → Research)

**Jump directly to:** Stage 8 (First Draft)

---

## Workflow

### Step 0: Validate the Outline (DO NOT SKIP)

Even with a complete outline, it's a DRAFT from the author. Before writing:

1. **Alex (Developmental):** Check structure, pacing, character arcs, plot holes
2. **Casey (Continuity):** Check internal consistency, timeline logic, character details match
3. **Riley (Research):** Flag authenticity issues, technical accuracy questions
4. **Quinn (Fact-Check):** Verify claims, terminology, procedural accuracy
5. **Present findings** organized by team member with clear options
6. **Get author confirmation** on every decision — never assume
7. **Update** outline and character files with agreed changes

Only after validation is complete do you proceed to writing.

---

### Step 1: Populate Knowledge Repository (15-30 minutes)

Extract from your outline and create structured reference files:

**Characters** (`/characters/`)
- One file per major character
- Include: age, role, goals, flaws, backstory, relationships, arc
- Example: `protagonist.md`, `supporting-character.md`

**Settings** (`/settings/`)  
- One file per major location
- Include: type, time period, plot significance, key details
- Example: `vilnius-lithuania.md`, `server-facility.md`

**Research needs** (`/research/`)
- Note topics needing verification
- Mark as [RESEARCH] tags in chapters as you write
- Riley investigates these as needed

### Step 2: Write Chapters Directly

**DO NOT use autonomous-booksmith** - that's for seed→full-development
**DO write directly** at 2,000-2,500 words per chapter

**Apply team standards as you write:**
- **Alex (Developmental):** Is this scene advancing structure/arc?
- **Jordan (Line):** Is the prose flowing? Voice consistent?
- **Casey (Continuity):** Does this match established character details?
- **Riley (Research):** Mark [RESEARCH] for technical details to verify

### Step 3: Batch Efficiently

Write in batches of 3-6 chapters (story sections), then:
1. Quick read-through for flow
2. Verify continuity against character/setting files
3. Check timeline alignment
4. Continue to next batch

**No multi-agent reviews until Stage 11** - keep momentum

### Step 4: Complete First Draft

Continue until outline is fully drafted. Then proceed to Stage 11 (Developmental Edit) for full team review.

---

## Real-World Example

**Starting point:** Complete draft outline with plot, characters, timeline

**What the team did BEFORE writing:**
- Full team review identified structural issues, continuity problems, and authenticity flags
- Author confirmed corrections (character ages, antagonist visibility, act stakes, etc.)
- Outline and character files updated with all agreed changes
- Knowledge repository populated with corrected character/setting files

**Key lesson:** The outline was a draft with character contradictions, logic holes, and missing tension in key sections. Team review caught all of this BEFORE any chapters were written.

**Never assume an outline is ready to write from.**

---

## Common Pitfalls

**❌ Using autonomous-booksmith pipeline**  
→ Too slow for existing outline. Write directly instead.

**❌ Perfectionism in early chapters**  
→ Forward motion. Editing comes in Stage 11.

**❌ Not populating knowledge repo first**  
→ Creates continuity headaches. Spend 15 minutes upfront.

**❌ Writing without referencing outline**  
→ Drift from planned structure. Keep outline visible.

---

## When to Use This Workflow

✅ Complete outline exists (all scenes plotted)  
✅ Characters are defined (goals, arcs, relationships known)  
✅ Setting is established (locations, worldbuilding clear)  
✅ You want to write NOW, not develop first

## When NOT to Use This Workflow

❌ Only have a concept/seed idea → Use standard workflow (Stages 0-4 first)  
❌ Characters feel flat/undefined → Do Stage 2 (Character Development)  
❌ Plot has holes → Do Stage 5 (Story Structure)  
❌ Setting needs research → Do Stage 3 (Research Deep Dive)
