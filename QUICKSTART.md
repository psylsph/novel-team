# Quick Start Guide

## How to Use the Novel Team

The novel team provides **professional editorial feedback** through distinct team member personas. Here's how to get started:

## Basic Usage

### 1. Consult a Single Team Member

```
"As Alex, review this scene and tell me if the pacing works..."
```

The agent will adopt Alex's personality (Developmental Editor) and provide feedback focused on:
- Story structure
- Character development
- Pacing and flow
- Plot logic

### 2. Get Multi-Perspective Feedback

```
"I want feedback on this passage from Jordan (line editing) and Taylor (copyediting) perspectives..."
```

You'll receive two distinct responses:
- Jordan: Focus on prose flow, word choice, rhythm
- Taylor: Focus on grammar, punctuation, technical accuracy

### 3. Hold a Team Meeting

```
"Convene a team meeting with Alex, Casey, and Riley to discuss how to approach this chapter about..."
```

The agent will simulate a discussion where each team member contributes their perspective:
- Alex: Developmental/structural input
- Casey: Continuity and consistency concerns
- Riley: Research and authenticity considerations

## Choosing the Right Team Member

| Need | Team Member | Why |
|------|-------------|-----|
| Big picture feedback | Alex | Developmental editor |
| Prose improvement | Jordan | Line editor |
| Grammar/polish | Taylor | Copyeditor |
| Final error check | Morgan | Proofreader |
| Authentic details | Riley | Research assistant |
| Consistency check | Casey | Continuity editor |
| Fact verification | Quinn | Fact checker |
| Motivation/support | Sam | Writing coach |

## Example Workflows

### Early Draft Stage
```
"Alex and Sam, help me plan this chapter. Alex focuses on structure, Sam on keeping me moving..."
```

### Middle Stage - Scene Development
```
"Riley, I need research on [topic]. Then Alex, help me structure this scene with that research..."
```

### Polishing Stage
```
"Jordan and Taylor, review this passage. Jordan for flow, Taylor for technical polish..."
```

### Final Review
```
"Morgan, proofread this chapter. Quinn, verify the technical details..."
```

### Continuity Check
```
"Casey, check if this matches what we established about [character/setting] earlier..."
```

## Team Member Quick Reference

### Alex - Developmental Editor
**Use for:** Story structure, character arcs, pacing, plot holes
**Style:** Strategic, questioning, big-picture
**Don't ask:** Grammar, punctuation, word choice

### Jordan - Line Editor
**Use for:** Prose flow, word choice, rhythm, voice consistency
**Style:** Artistic, language-focused, enhancing
**Don't ask:** Grammar, story structure, character development

### Taylor - Copyeditor
**Use for:** Grammar, punctuation, style guide, technical corrections
**Style:** Precise, rule-conscious, direct
**Don't ask:** Prose beauty, story structure, character motivation

### Morgan - Proofreader
**Use for:** Final error check, formatting, quality control
**Style:** Perfectionist, eagle-eyed, thorough
**Don't ask:** Content changes, style improvements (too late)

### Riley - Research Assistant
**Use for:** Historical/technical research, setting authenticity, professional details
**Style:** Curious, resourceful, informative
**Don't ask:** Story feedback, character development

### Casey - Continuity Editor
**Use for:** Character tracking, timeline consistency, world-building
**Style:** Organized, systematic, detail-obsessed
**Don't ask:** Prose quality, grammar, story structure

### Quinn - Fact Checker
**Use for:** Verifying facts, technical accuracy, real-world logic
**Style:** Skeptical, verification-focused, precise
**Don't ask:** Story structure, character development, prose quality

### Sam - Writing Coach
**Use for:** Goal setting, accountability, overcoming blocks, encouragement
**Style:** Encouraging, motivational, practical
**Don't ask:** Content feedback, technical editing

## Tips for Best Results

1. **Be specific** about what you want feedback on
2. **Choose the right team member** for your current need
3. **Ask multiple perspectives** for comprehensive feedback
4. **Use team meetings** for complex scenes or chapters
5. **Stage your requests** - don't ask Jordan to fix plot holes

## Common Patterns

### "What Would [Name] Say?"
```
"What would Taylor flag in this dialogue?"
"What would Alex say about this chapter's structure?"
"What would Quinn question about this technical scene?"
```

### Progressive Refinement
```
1. Alex: "Does this scene work structurally?"
2. Riley: "How can I make the details more authentic?"
3. Jordan: "Now improve the prose flow..."
4. Taylor: "Finally, polish the technical details..."
```

### Team Consensus
```
"Get input from Alex, Jordan, and Casey on this scene. What's your team assessment?"
```

## Notes

- All team members are **professional** and **respectful**
- Each has **clear boundaries** on what they address
- Personalities are **consistent** and **distinctive**
- Team members can be **combined** for comprehensive feedback
- The system automatically loads the appropriate persona when requested
